## Масштаб приложения и моделей

Само приложение сравнительно компактно: около 6,1 тыс. строк Python. Значительную часть возможностей дают готовые свободно распространяемые модели: Whisper large-v3-turbo для речи и Qwen3:4b для смыслового анализа. Ollama — средство запуска языковой модели, а не отдельная нейросеть. Модельные веса и контейнеры значительно больше собственного кода по размеру загрузки. Небольшой код не означает маленький установочный пакет или низкие требования к RAM.

Whisper распространяется по MIT, Qwen3-4B — Apache 2.0. У конкретных конвертированных артефактов и всех зависимостей сохраняются собственные условия. Источники: https://huggingface.co/openai/whisper-large-v3-turbo и https://huggingface.co/Qwen/Qwen3-4B .
