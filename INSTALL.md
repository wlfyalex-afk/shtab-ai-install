# Штаб.AI — установка и удаление

## Перед установкой: Windows и Ubuntu

1. **Антивирус.** На время установки приостановите антивирусную защиту либо добавьте установочные файлы и выбранную папку Штаб.AI в исключения. На Ubuntu этот пункт нужен, если установлен антивирус. После установки снова включите защиту и проверьте запуск приложения. Если антивирус блокирует локальный HTTPS-доступ, добавьте адрес Штаб.AI в исключения проверки защищённых соединений.
2. **Сертификат доверия.** После завершения установки добавьте публичный корневой сертификат `shtab-ai-root.crt` в доверенные центры сертификации браузера, которым будете пользоваться. Где взять файл и как его импортировать — в разделе [Сертификат в браузере](#сертификат-в-браузере-windows-и-ubuntu). Это нужно также на каждом другом компьютере, с которого открывается Штаб.AI.

## Ubuntu 24.04 LTS x64

Для установки или удаления достаточно соответствующей команды в терминале. Вручную скачивать комплект, распаковывать архив или выполнять `chmod` не нужно. Команда сама скачивает актуальный скрипт из ветки `main` GitHub в домашнюю папку и запускает его через `sudo`. Запуск происходит только после успешной загрузки.

Нужны интернет, `curl` и права `sudo`. Минимум: 4 логических ядра, 10 ГБ доступной RAM, 30 ГиБ свободного места на выбранном разделе; дополнительное место требуется для системного хранилища Docker. Подробности — в [README](README.md) и [дорожной карте](ROADMAP.md).

### Установка

```bash
curl -fL https://raw.githubusercontent.com/wlfyalex-afk/shtab-ai-install/main/Install-ShtabAI-Ubuntu.sh -o "$HOME/Install-ShtabAI-Ubuntu.sh" && sudo bash "$HOME/Install-ShtabAI-Ubuntu.sh"
```

Установщик предложит папку приложения, режим CPU/NVIDIA/AMD и локальный или сетевой доступ. Затем проверит кэш моделей, установит компоненты, проверит HTTPS, добавит сертификат в доверенные сертификаты Ubuntu и запросит данные первого администратора. При пустом или неверном вводе имени, логина, часового пояса или пароля установщик повторит соответствующий вопрос. Ctrl+C отменяет создание администратора; настройку можно продолжить командой `finish`. В конце создаст ярлыки, если доступен рабочий стол, и покажет адрес входа. Ярлык «Штаб.AI» открывает браузер пользователя. Если GNOME не разрешил запуск автоматически, нажмите на ярлык правой кнопкой и выберите «Разрешить запуск». Повторный `finish` обновляет прежний ярлык-ссылку.

Файлы и модели скачиваются автоматически. Первая установка требует загрузки больших моделей; сохранённый кэш используется повторно и проверяется по контрольным суммам. Кэш не гарантирует полностью автономную установку: системные пакеты, образы Docker и архив приложения могут обращаться к сети.

### Полное удаление

```bash
curl -fL https://raw.githubusercontent.com/wlfyalex-afk/shtab-ai-install/main/Uninstall-ShtabAI-Ubuntu.sh -o "$HOME/Uninstall-ShtabAI-Ubuntu.sh" && sudo bash "$HOME/Uninstall-ShtabAI-Ubuntu.sh"
```

Подтверждение: `DELETE-SHTAB`. Удалятся все контейнеры Штаб.AI, включая Ollama, пользователи, записи, результаты и папка приложения. Резервная копия автоматически не создаётся. Внешний постоянный кэш моделей, уже созданные резервные копии, Docker, драйверы и другие приложения сохраняются.

Если удаление завершилось с ошибкой, повторите его с сохранением журнала (при запросе снова введите `DELETE-SHTAB`):

```bash
curl -fL https://raw.githubusercontent.com/wlfyalex-afk/shtab-ai-install/main/Uninstall-ShtabAI-Ubuntu.sh -o "$HOME/Uninstall-ShtabAI-Ubuntu.sh" && sudo bash "$HOME/Uninstall-ShtabAI-Ubuntu.sh" 2>&1 | tee "$HOME/shtab-uninstall.log"
```

Журнал находится в `~/shtab-uninstall.log` и доступен обычному пользователю. Если папка приложения занята, закройте открытые в ней терминалы и файловые менеджеры, затем повторите команду из домашней папки. Скрипт завершает удаление и при отсутствии файла mount-службы; если отключить сам mount не удалось, папка данных сохраняется.


### Повторная установка из кэша

После завершённого удаления выполните ту же команду установки и выберите прежнюю папку приложения. По умолчанию кэш находится в `/var/cache/shtab-ai`; для отдельной папки приложения — рядом с ней, с суффиксом `-cache`. Если задавали `SHTAB_MODEL_CACHE`, снова укажите тот же путь. Создайте нового администратора и проверьте вход в браузере.

### Продолжение прерванной установки

Повторите команду установки: она обнаружит существующую установку и продолжит её без удаления данных. Для установленной актуальной версии также доступно:

```bash
sudo /opt/shtab-ai/shtabctl resume
```

Команда дождётся готовности компонентов и продолжит настройку сертификата, администратора и ярлыков. Если компоненты уже готовы, заключительные шаги можно повторить отдельно:

```bash
sudo /opt/shtab-ai/shtabctl finish
```

`sudo /opt/shtab-ai/shtabctl progress` только показывает состояние. Его 100% означает готовность компонентов, а завершение настройки подтверждается сообщением с адресом входа.

## Сертификат в браузере: Windows и Ubuntu

Сертификат создаётся вашей установкой Штаб.AI. Его берут с компьютера, где установлено приложение; скачивать сертификат с GitHub не нужно.

| Платформа приложения | Где взять публичный сертификат |
|---|---|
| Windows | В выбранной папке установки: `<папка установки>\shtab-ai-root.crt`. Например, `D:\Apps\ShtabAI\shtab-ai-root.crt`. При установке в папку по умолчанию: `%LOCALAPPDATA%\ShtabAI\ShtabAI\shtab-ai-root.crt`. Точный путь показывает ярлык «Управление Штаб.AI», пункт **6 — Адрес в сети и публичный сертификат**. |
| Ubuntu | В домашней папке пользователя: `~/shtab-ai-root.crt`, например `/home/nelly/shtab-ai-root.crt`. Установщик копирует туда публичный сертификат с правами для чтения обычным пользователем. Если файла нет, выполните `sudo /opt/shtab-ai/shtabctl certificate`. |

На Ubuntu папка приложения `/opt/shtab-ai` закрыта для обычного пользователя. Открывать её браузером или менять её права не нужно. Для уже установленной версии, которая ещё не копировала сертификат в домашнюю папку, выполните из терминала обычного пользователя:

```bash
sudo install -m 0644 -o "$USER" -g "$(id -gn)" /opt/shtab-ai/shtab-ai-root.crt "$HOME/shtab-ai-root.crt"
```

После этого в окне импорта браузера выберите файл `shtab-ai-root.crt` в своей домашней папке.

Для другого компьютера скопируйте на него только файл `shtab-ai-root.crt`. Папку `tls-data` и закрытые ключи не передавайте.

### Импорт в браузер

1. Откройте управление сертификатами в браузере, которым будете пользоваться:
   - **Яндекс Браузер:** введите в адресной строке `browser://settings/certificates`.
   - **Chrome / Chromium / Edge:** найдите в настройках «Сертификаты» или «Управление сертификатами» и откройте управление локальными сертификатами. В Windows оно может открыть системное хранилище.
   - **Firefox:** Настройки → Приватность и защита → Сертификаты → Просмотр сертификатов → Центры сертификации.
2. Нажмите **Импорт** и выберите `shtab-ai-root.crt` по пути из таблицы. Импортируйте его в **доверенные корневые центры сертификации** / **центры сертификации**. Если предлагается выбор доверия, отметьте доверие для идентификации веб-сайтов.
3. Полностью закройте браузер, откройте его снова и перейдите по адресу, который показал установщик или ярлык Штаб.AI.

Установщик уже добавляет сертификат в системное хранилище Windows или Ubuntu. Если браузер всё равно показывает предупреждение о недоверенном центре, выполните ручной импорт выше в своём пользовательском профиле браузера.

Справка производителей: [Яндекс — установка сертификатов на Linux](https://browser.yandex.ru/support/browser-corporate/ru/support/troubleshooting), [Mozilla — настройка центров сертификации](https://support.mozilla.org/en-US/kb/setting-certificate-authorities-firefox).

## Нейтральные имена установки

Новые установки используют `/opt/shtab-ai`, проект Docker `shtab-ai` и имя WSL `ShtabAI`. Прежняя структура не переименовывается автоматически: команда удаления распознаёт старую установку, а новая установка останавливается, если такая копия ещё существует. Перед сменой структуры сохраните нужные данные в резервную копию; для восстановления совместимой схемы поддерживается прежний формат копий. Внешний кэш сохраняется.

## Резервные копии и перенос данных

Полная копия: на Ubuntu `sudo /opt/shtab-ai/shtabctl backup`; на Windows откройте диспетчер → «Управление в Ubuntu» → пункт 5. Восстановление через пункт 7 заменяет всю базу, включая пользователей; перед этим создаётся страховочная копия. Внешний кэш моделей остаётся отдельно.

Отдельное совещание: в веб-интерфейсе откройте готовое совещание → «Перенести совещание» → скачайте архив. На Ubuntu или Windows откройте «Совещания → Импорт совещания», выберите ZIP и подтвердите добавление в текущую организацию. Существующие данные сохраняются. Для переноса такого архива права на системную папку backups не нужны.
